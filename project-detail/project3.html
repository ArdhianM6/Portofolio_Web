Marketplace App

Next.js React Supabase PostgreSQL Midtrans Vercel

A responsive full-stack marketplace built with Next.js, Supabase, PostgreSQL, and Midtrans. Customers can browse discounted products, choose delivery and payment options, apply vouchers with an instant total calculation, and review an itemized receipt before paying. Admins can also enter the customer storefront and return to the dashboard using a dedicated shortcut.

Key Features

Authentication

Sign in with Google, Facebook, or email through Supabase Auth, with an onboarding flow for new users.

Flash Sales

Time-limited prices with countdown timers. The app picks the active price: flash sale, discount, or regular.

Checkout & Payments

Midtrans Snap for e-wallet and bank transfer, plus QRIS through the Core API, with payment status updated by webhook.

Wallet Top-Up

Users top up their balance by scanning a QRIS code generated inside the app.

Delivery & Map

Addresses are picked on a Leaflet map. Shipping fees are tiered by distance, with normal, fast, and scheduled delivery.

Points, Vouchers & Referral

Points are earned automatically on paid orders and can be redeemed for vouchers. Referral codes are supported.

Real-Time Notifications

Order and wallet updates are pushed to users through Supabase Realtime.

Orders, Reviews & Wishlist

Order tracking with status history, product ratings and reviews, and a saved-items wishlist.

Admin Dashboard

Role-based access for admins to manage products and categories, with shortcuts to move between the dashboard and customer storefront.

Technical Highlights

  • Row Level Security: Supabase RLS policies restrict each user to their own data, and the service-role key is only used on the server.
  • Secure webhooks: the payment webhook verifies the Midtrans SHA-512 signature before updating any order or wallet top-up.
  • Database logic: order creation and voucher redemption run as PostgreSQL functions, and a trigger awards points when an order is paid.
  • Distance-based shipping: fees are calculated with the Haversine formula from the store to the selected map location.
  • Deployment: hosted on Vercel with environment variables for all secrets, connected to Supabase and Midtrans Sandbox.
