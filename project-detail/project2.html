Expense Tracker

React JavaScript CSS

Wallet Watch is a personal finance app built with React that lets users track income and expenses in real time. It includes a balance summary, a transaction list, simple ways to add and delete entries, and a dashboard with charts that show where the money goes.

Key Features

Record Transactions

Add income and expenses quickly with a single “Catat” (Record) button, and delete entries when needed.

Monthly Spending

A chart on the dashboard shows this month's spending so trends are visible at a glance.

Category Breakdown

A donut chart splits spending by category, showing which areas take the biggest share.

Total Balance

A balance card with a trend line keeps the current total and its movement in view.

Search Transactions

Find any entry by name, category, or tag from one search bar.

Dashboard & Reports

Switch between the dashboard overview and a reports view for a fuller look at the numbers.

Project Summary

  • Type: a web app for managing personal income and expenses.
  • Built with: React, JavaScript, and CSS.
  • Currency & language: Indonesian interface with amounts in IDR.
  • Hosting: deployed on Vercel, with the source code on GitHub.
