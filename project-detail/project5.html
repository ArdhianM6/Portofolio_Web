Titik Temu POS

PHP 8MySQLJavaScriptHTMLCSS

A point of sale system for a cafe team. Staff can sign in, manage a menu and stock, create dine-in or takeaway orders, record payments, and view a receipt after checkout.

Use the arrows or dots, or swipe on touch screens to browse all four screenshots.

This portfolio page shows screenshots from the local demo. Use the source repository to run the application with its demo database.

Key Features

Staff sign-in

Role-based access for administrators, managers, cashiers, and waiters.

Menu and stock

Manage product categories, prices, stock quantities, and item availability.

Order checkout

Build dine-in or takeaway orders, add customer details, and calculate tax and service charges.

Payment tracking

Record cash, QRIS, bank transfer, or debit payments and show change for cash orders.

Receipts and reports

Review completed transactions and use back-office sales and order reports.

Responsive interface

Cashier screens and operational views adapt to smaller displays.

Technical Highlights

  • Application structure: PHP use cases, domain logic, persistence adapters, and presentation controllers.
  • Order totals: server-side validation calculates subtotal, discount, tax, service charge, and payment due.
  • Data storage: MySQL persistence for staff accounts, products, inventory, and transactions.
  • Stack: PHP 8, MySQL, JavaScript, HTML, and CSS.
