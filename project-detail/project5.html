ALOVERA POS

React.jsNode.jsExpressPostgreSQLSupabaseVercel

ALOVERA is a responsive cafe point of sale system for staff to manage menus and stock, create dine-in or takeaway orders, record payments, and print receipts. The React interface is backed by a Node.js API and PostgreSQL database, with a live deployment on Vercel.

Key Features

Staff sign-in

Role-based access for administrators, managers, cashiers, and waiters.

Menu and stock

Manage product categories, prices, stock quantities, and item availability.

Order checkout

Build dine-in or takeaway orders, add customer details, and calculate tax and service charges.

Payment tracking

Record cash, QRIS, bank transfer, or debit payments and show change for cash orders.

Receipts and reports

Review completed transactions and use back-office sales and order reports.

Responsive interface

Cashier screens and operational views adapt to smaller displays.

Technical Highlights

  • Application structure: React and Vite frontend with a Node.js and Express serverless API.
  • Order totals: server-side validation calculates subtotal, discount, tax, service charge, and payment due.
  • Data storage: Supabase PostgreSQL with an isolated titik_temu schema for staff, products, inventory, and transactions.
  • Deployment: Vercel hosts the live React app and Node.js API, connected to PostgreSQL.
