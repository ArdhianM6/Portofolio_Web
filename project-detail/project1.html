Movie Search App

JavaScript API

A JavaScript movie search app that uses a movie API to show the title, poster, rating, and synopsis of each result based on what the user searches for. Beyond searching, it lets users browse trending titles, explore movies by region, filter and sort the results, and keep a list of favorites.

Key Features

Movie Search

Type a title and get matching results with poster, title, and rating shown on each card.

Trending Now

The home page highlights currently trending titles, so there is something to explore before searching.

Browse by Region

Separate views for Indonesian, English, Japanese, and Korean titles, plus a dedicated Anime section.

Filter & Sort

Narrow results by type and change the sort order to find what you want faster.

Favorites

Tap the heart on any movie to save it, and open the Favorites page to see your saved list.

Ratings at a Glance

Each poster carries its rating badge, so you can compare movies without opening them.

Project Summary

  • Type: a web app that fetches live movie data from an external API.
  • Built with: JavaScript, with movie data loaded from an API.
  • Interface language: Indonesian.
  • Hosting: deployed on Vercel, with the source code on GitHub.
