Screen Search

A responsive movie discovery app for exploring films, series, and anime. Search results open into shareable detail pages with ratings, cast and crew, personal viewing notes, and links to check legal streaming availability.

1 / 3

Screenshots change every 6 seconds. Hover or touch to pause, or use the arrows and dots to browse.

The app provides movie information and links to official viewing options. It does not host or stream copyrighted films.

Key Features

Movie discovery

Search titles and browse curated, regional, and anime collections with clear loading and error states.

Search controls

Filter by media type, sort results, and load additional result pages as needed.

Shareable details

Each title has a direct URL with synopsis, IMDb rating, genre, runtime, director, and cast.

Personal collections

Save favorites and watchlist titles, mark films watched, and keep recent searches locally.

Private viewing notes

Write a personal review for each title; notes stay in the current browser.

Legal viewing links

Find official streaming availability and trailers through external provider search links.

Responsive and accessible

Keyboard focus, meaningful labels, reduced-motion support, and layouts tuned for phones and desktop.

Technical Highlights

  • API integration: OMDb search pagination and on-demand title details reduce unnecessary detail requests.
  • Client-side routing: movie pages use direct IMDb-based URLs and support browser navigation.
  • State and persistence: favorites, watchlists, watched IDs, search history, and personal notes use browser storage with guarded parsing.
  • Resilience: requests handle stale responses, missing API configuration, API errors, and unavailable posters.
  • Stack: React 19, Vite, JavaScript, CSS, and OMDb API.
