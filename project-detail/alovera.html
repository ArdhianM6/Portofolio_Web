ALOVERA AI

ReactTypeScriptExpressSupabaseGemini API

ALOVERA is a personal AI workspace shaped around my AR identity, with Google and email sign-in, chat history, document tools, and a custom mascot.

Try ALOVERA: Open the public demo · View the source on GitHub
The interface is public. The AI API endpoint is not active on the current demo deployment, so AI replies may be unavailable.

Key Features

Authentication

Google OAuth and email OTP sign-in through Supabase Auth, with profile completion for new users.

Personal chat history

Search, reopen, and delete conversations saved separately for each signed-in account.

Document questions

Add TXT or Markdown content and ask the assistant to summarize or explain it.

AR mascot

A custom CSS mascot follows the pointer with both eyes and changes expression as the assistant works.

Technical Highlights

  • Frontend: React, TypeScript, and Vite for an interactive responsive workspace.
  • Backend: Express verifies Supabase sessions and keeps the Gemini API key server-side.
  • AI: Gemini generateContent with optional Google Search grounding for current-information prompts.
  • Privacy: Chat history is stored per account in the browser; document uploads are not persisted by the API.
